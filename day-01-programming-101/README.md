# Day 1: Programming 101

Welcome to **Day 1 of Kernel 2026**, a 7-day workshop organized by **KUMSC**.

This session introduces the fundamental ideas behind programming and builds the foundation needed for the rest of the workshop.

---

## Learning Objectives

By the end of this session, participants should be able to:

- Understand what programming is
- Explain how programs are used to solve problems
- Understand the relationship between problems, algorithms, and programs
- Understand basic programming concepts
- Explain variables and data
- Understand conditional statements and loops
- Understand functions
- Recognize different programming paradigms
- Understand the difference between procedural programming and object-oriented programming
- Read and reason about simple programs

---

## Topics Covered

1. What is Programming?
2. Why Do We Need Programming?
3. Problems, Algorithms, and Programs
4. Programming Languages
5. Programming Paradigms
6. Procedural Programming
7. Object-Oriented Programming
8. Variables
9. Data Types
10. Operators
11. Conditional Statements
12. Loops
13. Functions
14. Input and Output
15. Debugging
16. From Problem to Program

## Session Structure

The session focuses on understanding programming concepts before moving into more advanced programming topics throughout the workshop.

The emphasis is on understanding **how programmers think and solve problems**, rather than memorizing a particular programming language.
